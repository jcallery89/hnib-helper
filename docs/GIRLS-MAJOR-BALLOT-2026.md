## Restore into the tournament app (30 seconds)

The app's ballot data lives in the browser. If it is ever lost or overwritten:

1. Girls Major event, Ballot tab, "Import ballots (Gravity Forms entries)".
2. Paste the entries export (Forms, Import/Export, Export Entries on hnibonline.com - a fresh export always works, or the same CSV as this snapshot). Include the header row.
3. Load nominations: all picks and coach ranks come back. Set targets 36 / 18 / 6.
4. Re-mark invites from the Wave list below and any RSVPs already received.
5. Avoid keeping two tabs open on the same event - the second tab can save stale data over your work.
